# Release notes 1.0.1

Paste the English block into the changelog field of CurseForge and Modrinth. The French block is the translation, for review.

## English

**License and links update.** Nothing changes in game.

- The mod now ships under license 3.0, closed-source: the source code is no longer published. Playing it, running it on your server and including it in a CurseForge or Modrinth modpack that references the official file stay allowed, exactly as before. Releases already published keep the license they shipped with. Full terms: [license](https://github.com/THEFricadelle/mc-mods-issues/blob/main/licenses/create-belgian-snacks/LICENSE), [plain-language summary](https://github.com/THEFricadelle/mc-mods-issues/blob/main/licenses/create-belgian-snacks/NOTICE.md).
- Bug reports and suggestions now go to a single public tracker: [report a bug](https://github.com/THEFricadelle/mc-mods-issues/issues/new?template=bug-create-belgian-snacks.yml). Anything the license does not already allow: [ask for a permission](https://github.com/THEFricadelle/mc-mods-issues/issues/new?template=permission-request.yml).
- In the mod list, the issue link opens that bug report form and the website link opens the CurseForge page.

Requires Create 6.0.10 on NeoForge 1.21.1, on the client and the server.

## Français

**Mise à jour de la licence et des liens.** Rien ne change en jeu.

- Le mod passe sous la licence 3.0, en code fermé : le code source n'est plus publié. Y jouer, le faire tourner sur votre serveur et l'inclure dans un modpack CurseForge ou Modrinth qui référence le fichier officiel restent autorisés, exactement comme avant. Les versions déjà publiées gardent la licence avec laquelle elles sont sorties. Conditions complètes : [licence](https://github.com/THEFricadelle/mc-mods-issues/blob/main/licenses/create-belgian-snacks/LICENSE), [résumé en langage clair](https://github.com/THEFricadelle/mc-mods-issues/blob/main/licenses/create-belgian-snacks/NOTICE.md).
- Les signalements de bugs et les suggestions passent désormais par un seul tracker public : [signaler un bug](https://github.com/THEFricadelle/mc-mods-issues/issues/new?template=bug-create-belgian-snacks.yml). Pour tout ce que la licence n'autorise pas déjà : [demander une autorisation](https://github.com/THEFricadelle/mc-mods-issues/issues/new?template=permission-request.yml).
- Dans la liste des mods, le lien de suivi des problèmes ouvre ce formulaire de bug et le lien du site ouvre la page CurseForge.

Demande Create 6.0.10 sur NeoForge 1.21.1, côté client et côté serveur.
